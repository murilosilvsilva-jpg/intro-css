# Introdução ao CSS

 Nesse repositório, abordamos os principais conceitos nescessários pa começar a estilizar páginas **HTML** e compreender como o navegador interpreta e aplica regras de estilo.

## O que é o CSS?

 **CSS (Cascading Style Sheets)** é a linguagem utilizada para definir a apresentação visual dos elementos *HTML*

 ## Formas de aplicar o CSS
 - CSS Inline
 - CSS Interno
 - Css Externo
